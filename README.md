## Featured Missions / 重点项目

### [LLM Usage Collector](https://github.com/Dream22180971/LLM-Usage-Collector)

**One dashboard for your AI coding agents. / 一张终端仪表盘，汇总多个 AI Coding Agent 的 Token、模型和费用数据。**

Local-first usage aggregation for Claude Code, Codex, OpenCode, Copilot CLI, Qoder, Hermes and more.

### [TestPilotAgent](https://github.com/Dream22180971/TestPilotAgent)

**Turn requirements into structured test assets with AI. / 把需求文档变成结构化测试资产。**

An AI quality workbench evolving from test-case generation toward RAG, Agent, MCP and regression evaluation.

### [WorkLife Dashboard](https://github.com/Dream22180971/WorkLife-Dashboard)

**Turn the workday into a progress bar. / 把上班变成一场有进度条的游戏。**

A local-first Tauri desktop app for workday progress, reminders, widgets and Chinese work schedules.
