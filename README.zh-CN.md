## 我在做什么

| 方向 | 重点 |
| --- | --- |
| **AI 开发者工具** | AI Coding 工作流、Agent 工具、用量与可观测性 |
| **AI 质量工程** | RAG / Agent / MCP / Prompt / OCR 质量与回归测试 |
| **本地优先应用** | 小而实用、重隐私的桌面工具 |

我的原则很简单：**先解决真实问题，让项目 5 分钟内跑起来，再通过真实使用持续迭代。**

---

## 重点项目

### [LLM Usage Collector](https://github.com/Dream22180971/LLM-Usage-Collector)

**一张仪表盘汇总你的 AI Coding Agent。**  
本地聚合 Claude Code、Codex、OpenCode、Copilot CLI、Qoder、Hermes 等工具的用量数据。

### [TestPilotAgent](https://github.com/Dream22180971/TestPilotAgent)

**把需求转成结构化测试资产。**  
正在从“测试用例生成器”演进为覆盖 RAG、Agent、MCP 与回归评测的 AI 质量工作台。

### [WorkLife Dashboard](https://github.com/Dream22180971/WorkLife-Dashboard)

**把上班变成一条进度条。**  
一个本地优先的 Tauri 桌面应用，提供工时进度、提醒、Widget 与中国工作制支持。
